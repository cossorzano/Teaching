# Teaching

Teaching materials by C.O.S. Sorzano.

## Calculus

Interactive, narrated whiteboards that solve first-year Calculus exercises step by step, available in 11 languages (Español, English, Français, Português, 中文, हिन्दी, العربية, বাংলা, Bahasa Indonesia, اردو, Русский).

**👉 Explore them online: https://cossorzano.github.io/Teaching/Calculus/**

Each page runs directly in the browser: press ▶ (or the space bar) to play the step-by-step explanation with voice narration. The same lessons are available as videos on YouTube, in the playlists `Calculus_XX` (where `XX` is the language code).
